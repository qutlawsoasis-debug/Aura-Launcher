---
name: verify-diff
description: Сверить отчёт Antigravity с реальными изменениями на диске. Использовать автоматически, когда пользователь присылает отчёт, ответ или результат работы Antigravity, пишет «он закончил / готово / сделал», или даёт путь к файлу отчёта.
allowed-tools: Read, Grep, Glob, Bash
---
Отчёт агента: "$ARGUMENTS" (если пусто — отчёт из последнего сообщения пользователя; если его нет, попроси вставить отчёт или путь к нему).

1. `git status` и `git diff --stat`. Полный diff читай только по файлам, относящимся к задаче.
2. Сверь каждый пункт отчёта с diff: сделано / не сделано / сделано иначе.
3. Найди побочные изменения: файлы вне задачи, удалённый код, мусор (`.chrome_*`, скриншоты, временные скрипты).
4. Проверки:
   - менялись `.cs` / `.xaml` → `dotnet build`;
   - менялся HTML/CSS/JS → открыть страницу и проверить консоль на ошибки;
   - визуальные правки → смотреть скриншот, только если без него не понять.
5. Вердикт коротко:
   - ПРИНЯТО — одна строка;
   - или список проблем и корректирующий промт для Antigravity в формате /spec.
