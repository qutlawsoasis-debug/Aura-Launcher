# Отчёт о разработке JS-части моста игрового меню (Aura UI Ingame Bridge)

## 1. Что изменено по пунктам
1. **Локальный Lucide**:
   - Загружен `lucide.min.js` (версия 0.460.0) в папку `docs/redesign/ingame/lucide.min.js`.
   - В `index.html` заменён внешний скрипт unpkg на относительный локальный путь `<script src="./lucide.min.js"></script>`.
2. **Разрешение путей к ресурсам (`asset(path)`)**:
   - Написана функция `asset(path)`: при работе по HTTP (`location.protocol.startsWith('http')`) пути ведут на старые ассеты `../v3/public/assets/...`, при работе через `file:///` внутри мода — на локальные `./images/...` и `./fonts/...`.
   - Подключение шрифта `Onest` реализовано через динамическую инъекцию правила `@font-face` с правильным URL без сетевых 404 ошибок в консоли.
   - Фоны мира и скины персонажа (`.world`, `.head`) обновлены через `asset('images/...')`.
3. **Реализация моста `window.cefQuery`**:
   - Написана функция `sendQuery(obj, onSuccess, onFailure)` с парсингом JSON-запросов и ответов.
   - При старте в режиме `INGAME` (`?ingame=1`) отправляется `{"op":"get"}`:
     - `values` подставляются в структуру настроек `S` (render, sim, quality, fps, vsync, fov, bright, particles, clouds, master, music, blocks, mobs, players, sens, toggleSprint, raw, chatOpacity, language).
     - `keys` обновляют список горячих клавиш в детальном виде управления.
     - `player` подставляется в имя игрока в ESC-меню и в футере навигации.
     - `world` подставляется в название мира/сервера.
     - `fps` обновляет индикатор кадров.
4. **Отправка изменений настроек (`{"op":"set"}`)**:
   - Для слайдеров: отправка значения происходит по окончанию перетаскивания (событие `pointerup`).
   - Для чипов/переключателей/кнопок: отправка происходит сразу при клике.
   - Реализован механизм отката (rollback) значения и показ тоста с ошибкой (маленькая всплывающая пилюля снизу на 2 с) при ответе `{"ok":false}`.
5. **Действия в ESC-меню (`{"op":"action"}`)**:
   - «Открыть для сети» → `open_lan`.
   - «Достижения» → `advancements`.
   - «Статистика» → `stats`.
   - «Скриншоты» → `screenshots_folder`.
   - «Пригласить» → `invite` (при ответе `{"ok":false,"error":"not_ready"}` показывается тост «Скоро»).
   - «Продолжить» → `resume`.
   - «Выйти в меню» → `main_menu`.
6. **Локальные настройки**:
   - Тема (`aura_theme`) и эффекты стекла (`aura_fx`) сохраняются в `localStorage` и восстанавливаются при загрузке.
7. **Работа без `?ingame`**:
   - Без флага `ingame` макет работает полностью в автономном режиме без обращений к `cefQuery` и без ошибок в консоли браузера.

## 2. Лог запросов из заглушки моста

```json
{"op": "get"}
{"name": "open_lan", "op": "action"}
{"name": "invite", "op": "action"}
{"id": "render", "op": "set", "value": 24}
{"id": "vsync", "op": "set", "value": false}
{"id": "quality", "op": "set", "value": "fabulous"}
```

Дополнительно проверен откат значения при ошибке сервера:
- При отправке `{"id":"render", "op":"set", "value":32}` и ответе `{"ok":false, "error":"Memory limit exceeded"}` значение откатилось обратно на `12`, а внизу экрана отобразился тост «Memory limit exceeded».

## 4. Что не сделано (честно)
- Не трогались файлы Java (`aura-ui/**`), так как над ними параллельно работает другой агент.
- Не создавались физические папки `docs/redesign/ingame/fonts/` и `images/`, так как по заданию их распаковывает и собирает Gradle-таска `syncWeb`, а макет на HTTP использует резолвер `asset()`.
