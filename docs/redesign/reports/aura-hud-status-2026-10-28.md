Известные отклонения нынешнего рендерера от ранней схемы ТЗ: используется GlassSpring вместо Anim, glass-шейдер и Gaussian frost-пирамида вместо буквально названного SdfShader/dual Kawase. Это уже существовавший результат этапов2–2e; при переносе алгоритм не изменялся. `quality` сейчас LOW/MEDIUM/HIGH; добавление OFF предусмотрено отдельно. ТЗ не переписывается под видимость полного выполнения.

Типографика игры: Onest400/500/600/700; только недостающие греческие глифы Manrope; остальной отсутствующий символ — native fallback. Лаунчер отдельно: WPF Manrope, WebUI v3 Onest, без изменения его токенов.

Дальнейший порядок по поручению: меню-only smoke обеих версий → Off → актуальный HANDOFF → запрос нового ТЗ на этап3. HUD и его редактор в этой ветке не реализуются. Aura-Pack не публикуется.
