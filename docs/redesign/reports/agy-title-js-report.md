# Отчёт о разработке JS-моста главного экрана (title.html)

## 1. Что изменено
1. **Локальный Lucide и пути ресурсов**:
   - В `title.html` подключен локальный скрипт `<script src="./lucide.min.js"></script>` вместо внешнего unpkg.
   - Реализована функция разрешения путей `asset(path)`: на HTTP (`location.protocol.startsWith('http')`) пути ведут на `../v3/public/assets/...`, при работе внутри игры через `file:///` — на локальные `./images/...` и `./fonts/...`.
   - Шрифт `Onest` подключается динамически без сетевых 404 ошибок в консоли.
   - Аватар пользователя (`.user-head`) обновляется через `asset('images/Coock0ld.png')`.
   - Добавлен хелпер `getFallbackBg(id)` для выбора дефолтного фона `bg_*.jpg` по хешу ID мира/сервера, если иконка отсутствует (`null`).
2. **Протокол моста `window.cefQuery`**:
   - Функция `sendQuery(obj, onSuccess, onFailure)` для обмена строками JSON.
   - В режиме `INGAME` (`?ingame=1`):
     - Отправляется `{"op":"worlds"}`: полученные миры преобразуются в плитки с бейджами режима игры («Выживание», «Творчество», «Хардкор», «Приключение», «Наблюдатель»), форматированием размера («МБ» / «ГБ») и даты последнего входа. Обновляется счётчик в табе.
     - Отправляется `{"op":"servers"}`: формируется список серверов, обновляется счётчик.
     - Последовательный опрос пинга `{"op":"ping","address":ip}` для каждого сервера из списка: при успехе обновляется пинг, количество игроков и описание (MOTD), при недоступности — статус «Офлайн».
     - Кнопка «Играть»: для миров отправляет `{"op":"play_world","id":...}`, для серверов — `{"op":"connect","address":...}`.
     - Кнопка «+ Создать мир» (в конце карусели миров): отправляет `{"op":"action","name":"create_world"}`.
     - Кнопка добавления сервера в модальном окне: отправляет `{"op":"add_server","name":...,"address":...,"rp":"prompt|enabled|disabled"}`, после чего модалка закрывается и список серверов перезапрашивается.
     - Шестерёнка настроек (`#btnSettings` и `#btnStageOptions`): отправляет `{"op":"action","name":"options"}`.
3. **Обработка ошибок и тосты**:
   - Добавлен всплывающий компонент `.toast-pill` для отображения статусов и ошибок при сбоях запуска или добавления.
4. **Автономный режим (без `?ingame`)**:
   - Работает полностью на встроенных моковых данных, без вызовов `cefQuery` и без ошибок в консоли.
