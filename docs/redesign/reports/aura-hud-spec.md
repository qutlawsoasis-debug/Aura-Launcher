# ТЗ и правила: новый HUD и меню Aura внутри игры (с нуля, нативно)

Основа: исследование `docs/redesign/reports/clients-research.md` (Meteor, OneConfig, Elementa, owo-lib, LiquidBounce, ThunderHack, Wurst). Документ — главный источник правил для этой работы. Если что-то не сходится с CLAUDE.md/AGENTS.md по игре — прав этот файл. Правила изоляции и запреты git из AGENTS.md §0 действуют всегда.

---

## 0. Цель и границы

**Цель:** красивый интерфейс (Onest, стекло, акцент #64D2FF, Apple-уровень анимаций) внутри Minecraft 1.20.1 и 1.21.1 с минимальной ценой по FPS (цели — в §5, проверяются замером, не обещаются): HUD, главное меню, пауза, настройки и редактор HUD с перетаскиванием.

**Входит:**
- HUD: плашка «Aura · FPS · время», координаты, мини-плеер Aura Music, статусы, уведомления; хотбар и полоски — позже, отдельным этапом.
- Редактор HUD: перетаскивание, привязки, масштаб, скрытие, сброс.
- Оформление ванильных экранов: главное меню, пауза, настройки, миры/серверы, подсказки предметов.
- **Главное меню и экраны игры НЕ копируют лаунчер:** никакой капсулы внизу по центру, морфинга капсулы в панель и «острова» как в лаунчере (решение пользователя). Общее с лаунчером — только токены (шрифт, цвета, стекло, радиусы). Вид главного меню утверждается отдельным образцом на этапе 6.

**Не входит:**
- копия интерфейса лаунчера в игре (капсула внизу, «остров», морф капсулы в панель);
- браузер (MCEF/JCEF/Ultralight) в игре;
- переписывание логики Minecraft (сохранение миров, вход на сервер, применение настроек — только ванильными вызовами);
- выдуманные данные;
- копирование GPL-кода (см. §8).

## 1. Нерушимые правила

1. **Без браузера в игре.** Всё рисуется нативно в OpenGL кадра Minecraft.
2. **Ваниль — источник правды.** Экраны и действия остаются ванильными (Screen, options, KeyBinding, списки миров/серверов). Мы меняем вид и раскладку, а не поведение. Если наш экран не смог открыться — показать ванильный, не падать.
3. **Обе версии сразу.** Каждое изменение делается для 1.20.1 и 1.21.1. Общая логика — в одном общем исходном модуле (не копии), различия API — в тонком адаптере версии. Сигнатуры миксинов 1.21 сверять с `javap` по jar из `.gradle/loom-cache`. Компиляция ошибки миксинов не ловит.
4. **Изоляция и тесты.** Проверяет в игре ПОЛЬЗОВАТЕЛЬ после релиза. Агенты НЕ входят в мир и НЕ делают скриншоты. Единственный разрешённый запуск агентом — старт игры в `<мод>/run` (`$env:AURA_OFFSCREEN="1"; .\gradlew runClient`) до главного меню и выход — только чтобы поймать падения миксинов (их сборка не видит; так упал RC6). `%APPDATA%\.aura` и установленный лаунчер пользователя не трогать. Никаких флаг-файлов вне `run/`. До пользователя изменения доходят только релизом.
5. **Честные данные.** Если данных нет — пустое состояние, а не демо.
6. **Производительность — измеримые цели** (см. §5): соблюдать правила, цифры подтверждать замером. Режимы эффектов full / low / off обязательны.
7. **Git:** запрещены checkout/restore/stash/reset/clean, `gradlew clean`, `git add -A`. Чужие незакоммиченные файлы не трогать.

## 2. Архитектура

```
aura-<mod>-common/   — ОДИН общий исходный модуль (Gradle: общий srcDir/subproject), подключается в обе версии; копий нет
aura-<mod>/ (1.20.1) и aura-<mod>-1.21/ (1.21.1) — только адаптер версии, миксины и сборка
 └ common
    ├ render/   AuraRenderer   — пакетная отрисовка: rect (SDF), border, shadow, text, icon, clip
    │           SdfShader      — один шейдер: скругление, рамка, мягкая тень, заливка/градиент
    │           FontAtlas      — MSDF-атлас Onest (латиница + кириллица), метрики, fallback на ванильный шрифт
    │           BlurService    — один общий результат blur за кадр по запросу (dual Kawase: несколько проходов down/up по пирамиде ½→¼…; результат используют все панели)
    │           Anim           — время + easing, без аллокаций
    ├ ui/       компоненты: Button, Toggle, Slider, Segmented, TextField, List(виртуализированный), Card, Tooltip
    │           Theme          — токены (цвета, радиусы, отступы, шрифты), режимы full/low/off
    ├ hud/      HudElement (id, anchor, offset, size, scale, visible), HudRegistry, HudConfig (JSON, атомарная запись)
    │           элементы: StatusPill, Coords, MiniPlayer, Toasts …
    │           HudEditorScreen — перетаскивание, привязки, масштаб
    └ screens/  обёртки ванильных экранов (Title, Pause, Options, Worlds, Servers) — только вид
 └ adapter/ (по версии) — DrawContext/GuiGraphics, RenderSystem, шейдер-программы, сигнатуры миксинов
```

Ключевые принципы:
- **Один кадр — минимум проходов.** Все плашки, рамки, текст HUD собираются в буферы и рисуются пачками: SDF-элементы одним батчем (параметры радиуса/цвета/рамки — в атрибутах вершин, а НЕ в uniform на каждый элемент), текст — батч на страницу атласа.
- **Цель — без аллокаций в кадре** (проверяется профилем аллокаций, не обещание). Буферы, строки, массивы переиспользуются. Тексты, которые не меняются, кэшируются (раскладка строки — до изменения текста/масштаба).
- **Ресурсы грузятся один раз** (шейдер, атлас, иконки) при старте или первом показе — не в hover/render.
- **Модель HUD отдельно от рендера:** редактор и конфиг не зависят от того, чем рисуем.

## 3. Дизайн-система (токены, точные значения)

| Токен | Значение |
|---|---|
| Шрифт игры | Onest (MSDF), веса 400/500/600/700; Manrope — только fallback отсутствующих в Onest глифов (греческий). Если нет глифа в обоих — ванильный fallback только этого символа |
| Шрифт лаунчера (отдельная система, не менять здесь) | WPF: HeadingFont/MainFont = Manrope (`Styles/UiTheme.xaml`); WebUI v3: Onest (`docs/redesign/v3/tokens.css`, `assets/css/core.css`) |
| Акцент | #64D2FF, текст на акценте #00283A |
| Текст | #FFFFFF; вторичный rgba(255,255,255,.78); третичный .50; отключённый .32 |
| Стекло панели (full) | фон rgba(28,30,36,.55) поверх общего blur; блик сверху 1px rgba(255,255,255,.40)→.08; обводка 1px rgba(255,255,255,.10) |
| Стекло (low) | rgba(28,30,36,.82), без blur |
| Стекло (off) | rgba(28,30,36,.94) |
| Заливки (серые системные) | rgba(118,118,128,.24 / .36 / .50) |
| Радиусы | плашка 18 (pill = высота/2), карточка 14, кнопка 10, поле 10 |
| Тень | 0 10px 30px rgba(0,0,0,.35) (SDF-тень, не текстура) |
| Отступы | шаг 4: 4/8/12/16/24 |
| Размеры текста | HUD 13; строки меню 17; заголовок раздела 38 (в GUI-единицах при scale 2 — пересчитывать от GUI scale) |
| Анимации | 150–250 мс, ease-out cubic-bezier(.2,.8,.2,1); появление: opacity + translateY 4px; нажатие: scale .97 |

Правила вида: никаких эмодзи, неона, градиентных рамок и бейджей «ради красоты». Чёткость текста важнее эффектов. Токены сверять с `docs/redesign/concepts-v5/island.html`, но раскладку экранов лаунчера (капсула/остров) в игру не переносить.

## 4. Компоненты и поведение

- **Button / Toggle / Slider / Segmented / TextField / List / Card / Tooltip** — единые состояния: normal, hover, pressed, focused, disabled. Hit-зона = видимая форма.
- **Клавиатура:** Tab/Shift+Tab, Enter, Esc назад, стрелки в списках; фокус виден (обводка #64D2FF 2px).
- **Списки** (миры, серверы, моды, клавиши) виртуализированы: рисуются только видимые строки.
- **GUI scale:** всё масштабируется от GUI scale игры (в т.ч. подсказки предметов). Текст MSDF чёткий на 1–4 и «Авто».
- **Подсказки предметов:** наш стиль, но размеры и перенос — от ванильного GUI scale; цвет редкости только у названия.
- **Fallback:** символ отсутствует в атласе → ванильный шрифт (символы модов и ресурс-паков не ломать).

## 5. Производительность (бюджет и правила)

- **Цель для HUD (не обещание):** ≤ 0.3 мс CPU и ≤ 0.3 мс GPU на кадр при 1080p, full, все стандартные элементы видимы. CPU — spark/профиль; GPU — замер frame-time UI off vs on (spark GPU-время отдельно не покажет; при необходимости GPU timer query / RenderDoc).
- **Бюджет экрана меню:** плавно 60+ FPS на слабом ПК, без фризов при открытии (ресурсы прогреты).
- **Blur:** только когда видна стеклянная панель (меню/пауза/редактор); в HUD во время игры — по умолчанию БЕЗ blur (полупрозрачная плашка). Один общий результат blur за кадр (dual Kawase — это несколько проходов down/up, начиная с ½ разрешения; low — выкл). Не размывать заново для каждой панели.
- **Перерисовка:** статичные элементы не пересобираются каждый кадр; FPS/время обновлять не чаще 4 раз/с.
- **Запрещено:** радиальный blur с десятками выборок на каждую панель; копирование framebuffer на каждый элемент; создание текстур/шрифтов/шейдеров в render; rAF-подобные циклы в простое.
- **Замер (только когда разрешит пользователь, в изоляции):** одна сцена/разрешение/без лимита FPS; UI off vs on; холодный и прогретый запуск; frame-time p50/p95/p99 (это и есть итоговая цена); spark — только для CPU/аллокаций.

## 6. Редактор HUD

- Открытие: клавиша (настраиваемая, по умолчанию не занята) и кнопка в паузе.
- Модель элемента: `id`, `anchor` (9 точек: углы, края, центр), `offset` в долях экрана, `scale` (0.5–2), `visible`.
- Перетаскивание с мягкими привязками: к краям экрана, центру, краям и центрам других элементов, равным отступам; Shift — свободно без привязок. Направляющие линии #64D2FF 1px при привязке.
- Колесо/угловая ручка — масштаб; ПКМ — меню элемента (скрыть, сбросить, по центру).
- Кнопки: «Сбросить всё», «Готово (Esc)». Отмена Ctrl+Z (минимум 20 шагов).
- Сохранение: JSON в `config/aura-hud.json`, атомарно (tmp → move), с версией схемы и миграцией. Изменение размера окна/GUI scale не сбрасывает раскладку.

## 8. Лицензии

- **GPL (Meteor, LiquidBounce, ThunderHack, Wurst):** код НЕ копировать — только идеи и поведение, реализация своя.
- **LGPL (OneConfig, Elementa/UniversalCraft):** только как отдельная зависимость после проверки условий; код не вставлять.
- **MIT (owo-lib):** можно подключить как библиотеку (раскладка/события) с сохранением уведомлений; его blur не использовать.
- Шрифт Onest — проверить лицензию (OFL) и положить файл лицензии рядом с атласом.
- Каждое заимствование — строка в `docs/redesign/reports/third-party.md` (что, откуда, лицензия).

## 9. Рабочий цикл и проверка

1. ТЗ этапа → агент делает код в обеих версиях.
2. `gradlew build` обеих (НЕ clean).
3. **Старт обеих версий в изоляции до главного меню** (без входа в мир, без скриншотов): в логе 0 `Mixin apply … failed`, 0 `InvalidInjectionException`, 0 исключений нашего мода. Миксины, срабатывающие только в мире, — сверять сигнатуры по `javap`.
4. Архитектор проверяет дифф: обе версии, общий код только в общем модуле, нет аллокаций в render, нет демо-данных, ресурсы грузятся один раз.
5. Релиз (Aura-Pack) → Архитектор даёт пользователю список «где нажать — что должно быть» (3–8 пунктов).
6. Пользователь смотрит в игре и шлёт скрины → правки → снова п.2.

Скриншоты от агентов не нужны совсем — образцы (этап 1 и др.) пользователь смотрит сам после релиза. Отчёт агента: `docs/redesign/qa/<этап>/qa.md` — изменённые файлы, вывод сборки, строки лога запуска «чисто», список «что посмотреть», последней строкой ГОТОВО.
