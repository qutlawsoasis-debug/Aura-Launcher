# Отчёт по задаче: Главный экран игры (title.html) в стиле PS5-хаба

## 1. Реализованные экраны и компоненты
Файл: `docs/redesign/ingame/title.html`

- **Заставка-приветствие (`?screen=welcome`)**:
  - Аватар Coock0ld (`../v3/public/assets/images/Coock0ld.png`, pixelated лицо скина 84×84px с акцентным неоновым свечением).
  - Заголовок «Добро пожаловать, Coock0ld», бейдж «Aura Launcher», анимированный прогресс-индикатор.
  - Автоматический переход в хаб через 2 с при обычном входе (при `?screen=welcome` зафиксирован для скриншота).
- **Хаб миров (`?screen=worlds`)**:
  - Верхняя панель: переключатель «Одиночная игра (4)» / «Сетевая игра (3)», аватар игрока со статусом, часы реального времени, кнопка настроек.
  - Карусель плиток (PS5-стиль): выбранная плитка крупнее (148×148px против 128×128px), с яркой акцентной рамкой `var(--accent)`, неоновым свечением и бейджем режима.
  - Фон: полноэкранный арт мира (`bg_13.jpg`, `bg_5.jpg`, `bg_11.jpg`, `bg_7.jpg`), плавный crossfade через два независимых слоя `bg-layer`.
  - Сцена снизу-слева: бейдж сложности/параметров, крупное название, описание мира, кнопка «Играть» (`.btn-play` с акцентным свечением), кнопки опций и открытия папки.
  - Навигационные подсказки снизу-справа (`←/→`, `Enter`, `Tab`).
- **Хаб серверов (`?screen=servers`)**:
  - Вкладка «Сетевая игра» активна.
  - Плитки серверов: Aura · Новый мир, Hypixel, 2b2t, а также плитка «+ Добавить».
  - Отображение пинга, онлайна и IP-адреса. Кнопка «Подключиться».
- **Модальное окно «Добавить сервер» (`?screen=add-server`)**:
  - Размытый задний план (`backdrop-filter: blur(20px)` на оверлее).
  - Поля: Имя сервера, Адрес сервера.
  - Сегментированный переключатель: «Ресурспак сервера: Спрашивать / Да / Нет».
  - Кнопки: «Отмена» (`.btn-ghost`) и «Добавить сервер» (`.btn-submit`).
  - Закрытие по клавише Esc, крестику и клику вне карточки.
- **Экран загрузки (`?screen=loading`)**:
  - Название подключаемого мира / сервера.
  - Акцентная полоса прогресса с мягким неоновым свечением.
  - Подпись текущего этапа («Генерация ландшафта (74%)»).
  - Кнопка отмены (`Esc`).

## 4. Интерактивность
- Стрелки `←` / `→`: горизонтальное переключение выбранной карточки с кроссфейдом фонового арта.
- Клавиша `Tab`: переключение вкладок «Одиночная игра» / «Сетевая игра».
- Клавиша `Enter`: запуск загрузки выбранного мира/сервера.
- Клавиша `Esc`: закрытие окна добавления сервера или отмена загрузки с возвратом в хаб.
- Мышь: выбор плиток кликом, открытие модалки по кнопке «+ Добавить», валидация и добавление нового сервера в список.
