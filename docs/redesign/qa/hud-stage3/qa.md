## Источник MiniPlayer

**Нет.** В Java-модулях aura-glass/defaults отсутствует игровое API now-playing/Aura Music. `Services/Implementations/AudioService.cs` (`CurrentTrack`), `IAudioService` и `AnthemService` относятся к процессу лаунчера; игрового IPC/моста текущего трека не найдено. Имеющиеся named pipes обслуживают экземпляры лаунчера, не передают трек Minecraft.

Реализован `HudMusicSource` с snapshot `Track(title, artist, playing)` и previous/togglePlayback/next; `HudRuntime.MINI_PLAYER.source(...)` подключает реальный источник на клиентском потоке. NONE возвращает null, карточка скрыта даже при включении видимости; в настройках явно «нет источника». Три KeyBinding не назначены по умолчанию. Обложка и мышиные транспортные кнопки не подключались: действующего источника нет, его протокол и ресурсы не выдумывались. Демо-данных нет.
