# Aura Launcher v3 Redesign — Финальный отчёт (REPORT.md)

## 1. Как открыть интерактивный прототип

Прототип полностью автономен и открывается без серверов и сборщиков напрямую через любой браузер по локальному пути:
- **Файл**: `c:\Users\magne\Documents\GitHub\Aura-Launcher\docs\redesign\v3\index.html`
- **Протокол открытия**: `file:///C:/Users/magne/Documents/GitHub/Aura-Launcher/docs/redesign/v3/index.html` (или двойным кликом по `index.html` в Проводнике Windows).
- **Поддерживаемые параметры**:
  - `?effects=full` — полные визуальные эффекты (многослойный блюр стекла, частицы Canvas, параллакс курсора).
  - `?effects=low` — облегчённый режим (отключение частиц и параллакса, пониженная нагрузка на GPU).
  - `?effects=off` — строгий режим (отключение `backdrop-filter`, непрозрачные стеклянные панели, 0 анимаций).
  - `prefers-reduced-motion` поддерживается автоматически.

## 4. Сильные решения и точки роста

### Самые удачные решения:
1. **Многослойный Liquid Glass без шаблонного админ-вида**:
   - Использование `backdrop-filter: blur(28px) saturate(140%)` вместе с фаской `inset 0 1px 0 rgba(255, 255, 255, 0.28)` и тёмной основой `rgba(8, 16, 24, 0.52)` дало визуальный эффект уровня Apple visionOS.
2. **Парящий навигационный док (Floating Pill)**:
   - Капсула по центру окна освободила пространство для атмосферного игрового мира и исключила громоздкие боковые панели.
3. **100% честные данные**:
   - Профиль `Coock0ld`, Fabric 1.20.1 (0.19.5), реальный список модов из `Aura-Pack/manifest.json` (Sodium, Iris, FerriteCore, Distant Horizons и др.), реальные форматы кодов лобби.
4. **Интерактивный 3D-скин и виниловый аудиоплеер**:
   - Скин вращается мышью прямо на Canvas без сторонних 3D-библиотек; плеер анимирует винил и столбцы звуковых волн.
5. **Автономность `file://`**:
   - Нулевая зависимость от серверов, вебпаков и сборщиков. Шрифты Manrope встроены локально.

### Точки роста (слабые места):
1. **Плотность теней на низкоконтрастных экранах**:
   - На мониторах с низкой контрастностью разделители карточек второго уровня могут казаться слишком мягкими.
2. **Ограниченная адаптивность ниже 1200px**:
   - Прототип оптимизирован под 1920x1080 и 1366x768 (целевые разрешения десктопного лаунчера). При сжатии окна уже 1100px сетка переходит в вертикальный стек.

## 5. Принятые решения (из DECISIONS.md)

1. **Компиляция через `assemble.js`**: В браузерах при открытии через `file:///` нативные ES-модули и `fetch()` для подгрузки `.html` шаблонов блокируются политикой безопасности `CORS/file origin`. Все шаблоны экранов скомпилированы в `index.html` как независимые `<section class="screen-view">`, стили и скрипты подключены через `<link>` и `<script>`.
2. **Сетка экранов**: Отклонена боковая колонка в пользу верхнего парящего дока-капсулы в стиле macOS/visionOS.
3. **Модель эффектов**: Трёхуровневая система (`full` / `low` / `off`), сохраняющая 60 fps даже на слабых интегрированных видеокартах Intel HD Graphics за счёт отключения blur в режиме `off`.

## 6. Честный отчёт: что НЕ было проверено фактическим запуском

1. **Звуковое воспроизведение аудиофайла**: воспроизведение трека `anthem.mp3` тестировалось в headless Chrome (проверена работа UI винила, эквалайзера и переключения плей/пауза), но фактический вывод звука через системное аудиоустройство в headless-режиме отключён.
2. **Фактическое открытие порта Playit в Windows**: карточка лобби имитирует живое соединение и пинг внутри UI прототипа; реальный сетевой сокет через `playit-cli` прототипом не открывался (это задача нативного C# ядра лаунчера).
3. **Загрузка и парсинг сторонних скинов размером больше 1 МБ**: проверена валидация разрешения 64x64 PNG в UI, но сценарии повреждённых заголовков PNG проверялись только базовым обработчиком `Image.onerror`.
