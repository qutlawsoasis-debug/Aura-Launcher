# Aura Launcher v3 Redesign — Принятые решения (DECISIONS.md)

## Архитектурные решения

### 1. Единая точка входа и автономная работа без сборщиков
- **Решение**: `index.html` — единственная точка входа. Все экраны оформлены как независимые секции `<section class="screen-view" id="screen-[name]">` или подключаемые модули с хэш-роутингом (`#/play`, `#/lobby`, `#/friends`, `#/wardrobe`, `#/workshop`, `#/settings`).
- **Причина**: Гарантия мгновенного открытия по двойному клику в любом браузере и в WebView2 (`file:///...`) без необходимости запуска локального веб-сервера (`http-server`), без CORS-ошибок при `fetch()` шаблонов.

### 2. Список экранов по реальным возможностям лаунчера
Сверено с кодовой базой C# WPF (`Views/*.xaml`):
1. **Обзор / Играть (`#/play`)**: Статус сборки, выбор версии, большая кнопка запуска с состояниями (Готово к игре / Проверка файлов / Запуск Minecraft / Игра запущена), виджет профиля (Coock0ld, аватар, скин), виджет аудиоплеера с живым эквалайзером, лента новостей/моментов.
2. **Лобби и мультиплеер (`#/lobby`)**: Статус P2P-туннеля (Playit / UPnP), карточка активной комнаты или создание лобби с кодом приглашения (формат `AURA-XXXX-XXXX`), список игроков в лобби, кнопка прямого подключения.
3. **Друзья (`#/friends`)**: Список друзей с реальными статусами (В игре / В сети / Не в сети), отправка приглашения, карточка быстрого добавления.
4. **Гардероб (`#/wardrobe`)**: Интерактивный предпросмотр скина и плаща, переключатель slim/classic, кнопка загрузки нового скина/сброса на дефолтный скин Coock0ld.
5. **Мастерская (`#/workshop`)**: Список модов из сборки Aura-Pack (оптимизация, визуал, геймплей), шейдерпаки (Complementary, Sildurs), переключатели активности модов, быстрый переход к папке `mods/`.
6. **Настройки (`#/settings`)**: Управление памятью Java (RAM), папка игры (`%APPDATA%\.aura`), графические профили Minecraft, переключатель визуальных эффектов (Полные / Лёгкие / Выкл), поведение лаунчера при запуске, очистка кэша, диагностические логи.
7. **Системные модальные диалоги и оверлеи**:
   - Окно синхронизации и загрузки модпака (прогресс-бар, статус проверки SHA-256 файлов).
   - Диалог подтверждения очистки кэша.
   - Окно ошибки / недоступности сетевого туннеля.
   - Центр уведомлений (Toast messages).

### 3. Эстетика: Apple Liquid Glass + Gaming Visuals
- Многослойный `backdrop-filter: blur(var(--glass-blur)) saturate(140%)`.
- Верхний тонкий specular-блик: `inset 0 1px 0 rgba(255, 255, 255, 0.22)`.
- Никаких выдуманных неоновых радуг или кричащих цветов: фирменный янтарный акцент (`--accent: #F2A63C`), глубокая контрастная тёмно-синяя основа (`--bg-base: #050B0F`), чистые белые и полупрозрачные текстовые слои.
- Живые пружинные переходы (`cubic-bezier(0.2, 0.8, 0.2, 1)` / spring-feel), плавающий параллакс, взвешенные микрочастицы пыли в воздухе.


### 4. Экран «Друзья» — статус в реальном коде лаунчера
- **Вопрос**: Есть ли функционал друзей в реальном коде лаунчера или это выдуманная фича?
- **Аудит кодовой базы C# и TypeScript**:
  - **C# Сервисы**: `Services/Interfaces/IFriendService.cs`, `Services/Implementations/FriendService.cs` — полноценный рабочий сервис.
  - **WPF Представления**: `Views/FriendsView.xaml`, `Views/FriendsView.xaml.cs`, `ViewModels/FriendsViewModel.cs`.
  - **Модели данных**: `Models/FriendModels.cs` (`FriendPresenceItem`, `FriendRequestItem`, `IncomingInviteItem`, `UserProfileSnapshotDto`).
  - **Бэкенд**: `lobby-api/src/friendRoutes.ts` и `lobby-api/api/friends/` (маршруты на Vercel Serverless с хранилищем Upstash Redis KV).
  - **Тесты**: `tests/AuraLauncher.Tests/FriendsAndLobbyScenarioTests.cs`.
- **Фактические возможности в коде**:
  - Генерация и привязка персонального кода друга (`CurrentFriendCode`);
  - Отправка и принятие заявок в друзья (`SendFriendRequestAsync`, `RespondFriendRequestAsync`);
  - Отслеживание статусов присутствия (`FriendPresenceItem`: в игре, в сети, не в сети, текущее лобби);
  - Отправка приглашений в приватный P2P-туннель лобби (`SendInviteAsync`);
  - Удаление из друзей (`RemoveFriendAsync`).
- **Решение**: Экран «Друзья» в Aura Launcher v3 является 100% реальной функциональностью проекта. Для автономного HTML-прототипа тестовые сущности вынесены в `assets/js/demo-data.js` с явной отметкой `// DEMO`.
