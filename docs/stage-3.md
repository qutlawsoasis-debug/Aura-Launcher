# ЭТАП 3: обновление сборки через manifest.json

Прочитай AGENTS.md. Окно обновления и самообновление лаунчера уже сделаны (этап 4),
здесь только сборка.

## ЧАСТЬ A: репозиторий Aura-Pack (рабочая копия C:\AuraPackWork\pack)

1. pack.settings.json в корне: { "name": "Aura", "minecraft": "1.20.1", "fabricLoader": "0.19.5",
   "forceConfigs": [] } (forceConfigs: пути из config/, которые лаунчер перезаписывает всегда).
2. options.txt в корне сборки (шаблон ПО УМОЛЧАНИЮ для новых игроков): возьми
   D:\.minecraft\options.txt и оставь ТОЛЬКО ключи: version, lang:ru_ru, guiScale:2,
   fullscreen:true, resourcePacks (список включённых ресурспаков из моей сборки).
   Никаких клавиш, чувствительности, имён и путей. Покажи мне итоговый файл и жди ответа.
3. tools\make-manifest.ps1: сканирует mods, shaderpacks, resourcepacks, config и options.txt,
   пишет manifest.json: { "name", "packVersion" (UTC "yyyyMMdd.HHmm"), "minecraft",
   "fabricLoader", "files": [ { "path", "sha256", "size", "mode": "sync"|"default" } ] }.
   mode: mods, shaderpacks, resourcepacks = "sync"; config/* и options.txt = "default"
   (кроме forceConfigs = "sync"). Пути с прямым слэшем, стабильная сортировка. Исключить:
   .git, .gitignore, manifest.json, pack.settings.json, tools.
4. tools\publish.ps1: запускает make-manifest, показывает сводку (добавлено, удалено, изменено,
   размер), просит подтверждение, git add, commit "pack <packVersion>", push в main.
5. Сгенерируй первый manifest.json и запушь. Проверь raw-ссылку
   https://raw.githubusercontent.com/qutlawsoasis-debug/Aura-Pack/main/manifest.json (200).
6. Просканируй config\ на личные данные (абсолютные пути D:\, C:\Users\magne, имена, токены):
   только сообщи файлы и строки, ничего не меняй без моего ответа.

## ЧАСТЬ B: лаунчер (интерфейс IPackUpdateService)

Заменяет старый GitHubUpdateService и заглушку из окна обновления; поле CurrentVersion и
загрузку zip из Releases удалить.

7. Константа DefaultPackRepo = "qutlawsoasis-debug/Aura-Pack", ветка main. В config поле
   PackRepo ("Расширенные"); миграция: значение пустое или "qutlawsoasis-debug/Aura"
   заменить на константу.
8. CheckAndApplyAsync(progress, ct) вызывается в окне обновления при запуске (после обновления
   лаунчера) и в начале нажатия ИГРАТЬ/УСТАНОВИТЬ, только когда игра не запущена:
   а) скачать manifest.json (таймаут 8 с, добавь ?t=<ticks> против кеша);
   б) нет сети: если сборка уже ставилась (есть %AppData%\Aura\pack-state.json), продолжить
      без обновления и сказать об этом; если не ставилась, ошибка "Нужен интернет для
      первой установки";
   в) packVersion совпал с сохранённым: быстрая проверка (файлы на месте, размеры);
      при расхождении полная проверка SHA-256;
   г) иначе составить план: скачать, заменить, удалить; "sync": скачать, если файла нет
      или хеш другой; "default": только если файла нет (существующий не трогать);
   д) удалять только *.jar из mods\, которых нет в манифесте; в других папках ничего не
      удалять;
   е) скачивание: один HttpClient, параллельность 6, до 3 попыток с паузой 1-2-4 с, запись в
      <файл>.part, проверка SHA-256, атомарная замена, остатки .part удалять при старте;
   ж) прогресс по байтам, МБ/с, "Обновление сборки: файл N из M"; отмена через CancellationToken;
   з) успех: записать pack-state.json и LastUpdateUtc, обновить на главной "Модов установлено"
      и "Обновлено";
   и) не удалось обновить (кроме отсутствия сети при уже установленной сборке): игру не
      запускать, "Сборка не обновилась, повтори", причина в лог.
9. options.txt: сборка кладёт шаблон в игровую папку, если файла нет (mode default). Логика
   создания options.txt в лаунчере остаётся запасной (если после синхронизации файла всё
   равно нет). Существующий options.txt игрока не менять никогда.
10. Версия загрузчика: если в манифесте есть fabricLoader, использовать её вместо константы
    (старые версии не удалять).
11. Безопасность: скачивать только файлы из манифеста и только с raw.githubusercontent.com по
    HTTPS; отвергать пути с "..", абсолютные, с диском и обратными слэшами, и всё, что не
    начинается с mods/, shaderpacks/, resourcepacks/, config/ (кроме файла options.txt в корне);
    максимум 200 МБ на файл.

## ПРОВЕРКА

- Юнит-тесты на временных папках: добавление, замена, удаление мода; default не
  перезаписывается; forceConfigs перезаписывается; лишний jar в mods удаляется; пользовательский
  файл в shaderpacks остаётся; "../x" отклоняется; обрыв и повторный запуск докачивает;
  повреждённый jar восстанавливается.
- Реальный прогон на пустой GameDir: окружение и сборка скачиваются с GitHub, в mods ровно
  58 jar, запуск игры: в latest.log "Setting user:" и "Backend library", нет "Incompatible mods
  found", "Mod resolution failed", "Mixin apply failed", "Exception in thread". "Loading N mods"
  с 58 не сравнивать (вложенные jar). В отчёте: размер, время первой установки (цель меньше 3 минут).
- Проверь, что в запуск попали ресурспаки и шейдеры из шаблона (Iris видит шейдер, язык русский).
Отчёт: что сделано, результаты тестов, что НЕ проверено.
