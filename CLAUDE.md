## Принятые решения
- Интерфейс v3 встраивается в WPF через WebView2. C#-сервисы остаются как есть.
- Сборка v3 — Vite (решено 2026-10-21): ES-модули вместо глобальных скриптов, dev-сервер с мгновенным обновлением (в Debug WebView2 смотрит на него), хэши файлов против кэша, однофайловая версия через vite-plugin-singlefile. Самописные assemble.js/build_standalone.js убираются.
- Tailwind не вводим: CSS на токенах и общих классах компонентов (`.btn`, `.row`, `.seg`…) уже есть. Вернуться, только если интерфейс сильно разрастётся.
- Позже такой же стиль нужен в меню внутри игры (Fabric, Java): переносится дизайн-система, а не HTML.

## Концепция дизайна: «Остров» (утверждена 2026-10-21)
- Эталон: `docs/redesign/concepts-v5/island.html`. Всё новое сверять с ним. Старые v3-экраны и концепты v4 эталоном не считаются.
- На экране только мир на весь экран и одна стеклянная капсула внизу по центру. Никаких окон, сайдбаров и дашбордов.
- Капсула морфится: покой (аватар, ник, «Играть») → наведение (меню разделов) → раздел (капсула вырастает в панель раздела). Внизу раскрытой панели строка разделов и «Играть»; закрытие ✕ или Esc.
- Разделы: Карта, Лобби, Друзья, Гардероб, Мастерская, Настройки. Карта разворачивает капсулу почти на весь экран.
- «Играть» → прогресс внутри кнопки → капсула «В игре».
- Стекло как у Apple: светлое матовое, `blur(44px) saturate(190%)`, блик по верхнему краю, серые системные заливки внутри (`rgba(118,118,128,.24/.36/.5)`), белый текст с прозрачностью.
- Акцент — systemCyan `#64D2FF` (текст на нём `#00283A`). Янтарный больше не используется.
- Шрифт Onest, крупная типографика (заголовок раздела 38px, строки 17px), минимум бейджей.
- Гардероб — исключение из эталона: настоящий 3D-скин через skinview3d (WebGL, локальный файл без CDN), с анимацией idle/ходьбы, плащом и вторым слоем. Рендер на паузе, когда раздел закрыт.
- Карта: источник — тайлы JourneyMap из игры (своего сервера нет, мир хостит друг), позже позиции друзей через свой Fabric-мод. Пока процедурная заглушка.

## Производительность
- Живой `backdrop-filter` — один слой (капсула), только в режиме full. В low/off стекло плотное без размытия.
- Анимации только через `transform` и `opacity`. Исключение — морф размеров капсулы (width/height); если на слабом ПК тормозит, перевести на FLIP/`clip-path`. Частицы и циклы rAF на паузе, когда окно свёрнуто или ничего не движется.
- Режимы эффектов full / low / off. Шрифты в woff2, картинки в WebP.

## План
1. Разведка — отчёт `docs/redesign/reports/v3-audit.md`.
2. Чистка: мусор (`.chrome_*` в v3), источник правды, сборка.
3. Перенос эталона «Остров» в v3: токены и оболочка-капсула → разделы → карта.
4. Интеграция: Vite → WebView2 и мост к C# (по `docs/redesign/reports/integration-map.md`) → подключение разделов.
5. Оптимизация и проверка на слабом ПК.

## Автоматический рабочий цикл (без команд)
- Пользователь просит промт или ТЗ для Antigravity → сразу работать по скиллу `spec`.
- Пользователь присылает отчёт Antigravity или пишет «готово» → сразу работать по скиллу `verify-diff`. Если ПРИНЯТО — тут же предложить промт на следующий шаг плана.
- Отчётам агента не доверять: сверять с `git diff` и проверять глазами.
- C#: `dotnet build`. HTML: `node tools/smoke.js` в v3 + открыть страницу и проверить консоль (сбросив кэш).
