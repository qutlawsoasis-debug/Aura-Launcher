# Aura Launcher: правила проекта

Проект: лаунчер Minecraft (Fabric 1.20.1) для игры с друзьями. WPF, .NET 8, MVVM, DI.
Запуск игры напрямую через CmlLib.Core, без TLauncher. Конфиг: %AppData%\Aura\config.json,
единый источник правды через IConfigService (ConfigChanged). Сборка обновляется из GitHub.

Правила работы:
1. Делай только то, что просят в задаче. Новые фичи, экраны, надписи и эффекты по своей
   инициативе не добавлять.
2. Никаких выдуманных данных в интерфейсе (фейковый онлайн, пинг, счётчики). Показывать
   реальное или "—".
3. Не пиши "готово", "проверено", "работает", если ты это не проверил. В отчёте отдельным
   пунктом перечисляй, что НЕ проверено фактическим запуском.
4. Любая UI-задача: прочитай навык aura-ui-design ДО работы, сделай скриншоты окна и
   изучи их ПОСЛЕ работы.
5. XAML: Color и Brush разные ресурсы (Background принимает только Brush); Freezable-объекты
   (кисти, материалы, битмапы) замораживать; не хардкодить пути (D:\ и т.п.) и цвета в разметке.
6. Если не уверен, как делают в популярных продуктах, открой и посмотри их через браузер,
   а не полагайся на память: твои знания устарели.
7. Запуск игры считается проверенным только если процесс жив и в latest.log есть Reloading ResourceManager и Created: ...atlas. Строка Backend library: LWJGL не доказывает запуск.
